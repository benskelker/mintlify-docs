CyberArk supports integrating Audit with SIEM applications so that you can monitor your services' audit events in any third-party SIEM application.

The SIEM integration API retrieves events from the previous 7 days only.

SIEM integrations documentation has moved to the Administration space. Go to [Export to SIEM](/admin-space/latest/en/content/siem-integration/siem-export-main).
