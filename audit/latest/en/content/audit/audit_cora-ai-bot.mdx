Hi, I'm CyberArk's AI chatbot.

CyberArk's CORA AI chatbot transforms the way you interact with the Identity Security Platform. With CORA AI capabilities, you can query data from your CyberArk environment or perform actions that bolster your identity security program outcomes. As a conversational interface, the CORA chatbot enables you to engage with CyberArk's services through natural language. It can understand your queries, provide context-relevant information, and run commands to assist in performing your tasks. The CORA chatbot helps you navigate the complexities of identity security and simplifies your daily tasks.

CyberArk's CORA AI chatbot uses Azure OpenAI as the Gen AI tool. You can read more about CyberArk's commitment to [Responsible AI](https://www.cyberark.com/trust/responsible-ai/).

For more information about CyberArk's CORA AI capabilities, see[CyberArk's CORA AI](/ai/latest/en/content/ai/coraai-introduction).

CyberArk CORA AI may be subject to updates and improvements over time.

CORA AI chatbot Audit actions
-------------------------------------------

The following sections describe how CyberArk's CORA AI can assist you in performing actions in the Audit space.

The CORA AI chatbot is available for users that are assigned to the built-in global auditor role. For more information about user roles, see [ISPSS user roles](/identity-administration/latest/en/content/coreservices/getstarted/ispss-user-roles).

### Audit logs

The CORA AI chatbot can assist in retrieving and displaying the latest audit logs.

### Create reports

The CORA AI chatbot can assist in creating audit reports.
