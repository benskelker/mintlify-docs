This method retrieves a session ID and returns a URL with the download location for the session recording.

Required user permissions
---------------------------------------

To run this API, the user must be assigned the Auditor (global auditor) role in Identity.

Recording API base URL
------------------------------------

Copy to clipboard`https://&lt;subdomain&gt;.recording.cyberark.cloud/`

URL
-----------------

Copy to clipboard`&lt;recording_api_url&gt;/api/recordings/&lt;session_id&gt;/download`

Make sure there are no spaces in the URL.

The following characters are not supported in URL parameter values: + & %

Resource information
----------------------------------

| HTTP method | Content type |
| --- | --- |
| GET | application/json |

URL parameters
----------------------------

Parameter Description
session_id The session event ID used to return a URL with the location where you can download the session recording.

Type: String

Body parameters
-----------------------------

None.

Result
--------------------

The following parameters can appear in the result

| Parameter | Description |
| --- | --- |
| url | A temporary link used to download the recording file. Type: String |

Copy to clipboard
```
{
    "url" : "LINK-OF-TEMPORARILY-ACCESSIBLE-RECORDING"
}
```
