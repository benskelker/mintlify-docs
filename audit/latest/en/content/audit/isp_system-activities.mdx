This topic describes the system activities that you can view in the Audit space.

Overview
----------------------

The Activities page in the Audit space enables system and tenant administrators, and auditors to view events such as user access, user activities, time and date of these activities, and other relevant data.

This information can help analyze failures, identify suspicious activities, and perform forensic investigations.

System activity information is also needed for record of proof and accountability, and to demonstrate compliance with external certification programs.

You can create reports from the system activity. See [Generate activity reports](/audit/latest/en/content/audit/isp_activities-reports) for more information.

View general audit information
--------------------------------------------

To refresh the view:

Click refresh in the upper right area of the window.

To rearrange, add, or remove property columns in the Activities table:

1.   Click Table columns settings in the upper right area of the window.

The Status and Timestamp columns are default properties and cannot be removed from the table.

2.   To add a property to the table or remove a property from the table, click the radio button next to the property.

3.   To change the position of a column in the table, click and drag the column property to the location that you want.

You can also rearrange the property columns in the table by clicking and dragging a column in the table.

4.   To revert back to the default settings, click Reset to default.

5.   Click Save.

View an event's details
-------------------------------------

Click the row of the event whose details you want to view.

See [Audit properties](/audit/latest/en/content/audit/isp_system-activities) for more information about each property field.

Filter and search
-------------------------------

You can use the following filters to customize your Activities view:

*   Time range

*   Actions

*   Service

*   Property

To filter by a specific property's value:

*   In the Filter by field, select the property from the list or start typing the property's name.

*   In the Search field, enter the value of the property that you want to find. When searching for a service data value, you must enter the exact value.
