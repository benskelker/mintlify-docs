This topic describes the CyberArk Identity audit events and codes.

Audit events by component and activity
----------------------------------------------------

Audit events and codes are available for the components and activities listed below.

| --- | --- | --- |
| CyberArk Identity user |

|  | Delete user | delete-user |
| CyberArk Identity |
|  | Create role | Role creation |
|  | Update role | Role update |
|  | Edit role | Role modification |
|  | Delete role | Delete a role |
| Authorize and authenticate |
|  | Log in | Login |
|  | MFA summary | Multifactor summary |
|  | Create authtoken | OAuth token creation |
|  | Log out | Logout |
| Policy |
|  | Add policy | Add a policy set |
|  | Modify policy | Modify a policy set |
|  | Delete policy | Delete a policy set |
| Application |
|  | Add application | Add Application |
|  | Modify application | Modify Application |
|  | Launch application | Admin Application launch |
|  | Delete application | Delete Application |

|  | Launch self-service application | Personal apps launched |
|  | Launch Gateway application | Application launch |
| Generic |
|  | Invite user | User invited |
|  | Generate MAUs (monthly active users) report at the end of the month | MAU Aggregation |
| Lifecycle Management |
