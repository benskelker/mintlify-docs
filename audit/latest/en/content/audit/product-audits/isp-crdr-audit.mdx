This topic describes the audit events and codes related to Cross-Region Disaster Recovery (CRDR).

For more information about how a CRDR incident impacts Audit functionality, see [CRDR Audit functionality](/cross-region-dr/latest/en/content/crdr/crdr-audit).

Audit events by component and activity
----------------------------------------------------

Audit events and codes are available for the component and activities listed below.

CRDR audit events by component and activity| Component | Activity |
| --- | --- |
| CRDR | * Failover to DR region * Failback to main region |

Audit codes
-------------------------

The following table describes the CRDR audit codes.

CRDR audit codes| Audit code | Audit type | Description |
| --- | --- | --- |
| CRDR0001 | Info | The failover to the DR region has been successfully completed. |
| CRDR0002 | Info | The failback process to the main region has been successfully completed. |
