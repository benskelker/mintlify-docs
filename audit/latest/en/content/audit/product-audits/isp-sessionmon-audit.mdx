This topic describes session monitoring audit events.

Audit events
--------------------------

When an auditor downloads or plays a session recording in Session monitoring, an event is sent to the Audit service.

| Audit code | Event name | Description |
| --- | --- | --- |
| RECI101 | Request Recording Access | A user requested access to a session recording. |
