This topic describes the Privilege Cloud audit events and codes.

In addition to the Privilege Cloud audit codes that are displayed in the Audit space, more Privilege Cloud events can be viewed in the Privilege Cloud[User and Safe Activities report](/privilege-cloud-shared-services/latest/en/content/privilege cloud/privcloud-reports) or sent to your SIEM solution. See [Manage audits](/privilege-cloud-shared-services/latest/en/content/privilege cloud/privcloud-audit-action-codes) in the Privilege Cloud documentation.

Audit events by component and activity
----------------------------------------------------

Audit events and codes are available for the components and activities listed below.

| --- | --- |
| Privileged account management | * View * Create * Store * Move * Delete |
| Approval workflow | * View Open * Confirm * Reject * Hide * Delete |

| Safe and member management | * Add * Update * Delete * Clear * Compress * Remove |
| User group and location management | * Add * Update * Store * Clear * Delete |
| Application management | * Add * Delete |
| User login | * Login status * Authentication |
| Master policy audits | * Change |
| Report management | * Add * Run * Send * Hide * Edit * Delete |
| Privileged account auto-detection | * Add * Update, * Archive * Start * End * Delete |
