This topic describes the Secrets Manager - SaaS audit events.

Events are created for requests sent to your Secrets Manager - SaaS deployment, including requests that are forwarded from an Edge to Secrets Manager - SaaS.

Secrets Manager - SaaS Edge audits and logs are not available from the Audit space. They are available from the Secrets Manager - SaaS Edge machine. For more information, see Audits and Logs.

Audit events
--------------------------

This section lists examples of Secrets Manager - SaaS audit events.

Secrets Manager - SaaS audit event examples| Event name | Description |
| --- | --- |
| authn-authenticate | A workload or user authenticated to Secrets Manager - SaaS |
| update-update | A secret value was updated |
| fetch-fetch | A secret was retrieved |
| policy-add | A Secrets Manager - SaaS policy was created |
| policy-change | A Secrets Manager - SaaS policy was updated |
| policy-remove | A Secrets Manager - SaaS policy was removed |
