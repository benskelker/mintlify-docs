This topic describes the audit events and codes related to Discovery & Context.

Audit events by component and activity
----------------------------------------------------

Audit events and codes are available for the components and activities listed below.

Discovery & Context audit events by component and activity| Component | Activity |
| --- | --- |
| Secrets | * Create * Delete * View (Query) |
| AI agents | * Create * Delete * View (Query) |
| Workloads | * Create * Delete * View (Query) |

Audit codes
-------------------------

The following sections describe the audit codes according to functionality.

Secrets inventory audit codes| Audit code | Audit type | Description |
| --- | --- | --- |
| DSC0001 | Info (Success) | A user uploaded secrets using the `AddReplaceSecrets` API. |
| DSC0000 | Failure | A user could not upload secrets using the `AddReplaceSecrets` API. |
| DSC0002 | Info (Success) | A user deleted secrets using the `DeleteSecrets` API. |
| DSC0003 | Failure | A user could not delete secrets using the `DeleteSecrets` API. |

| DSC0019 | Failure | A user could not delete AI agents using the `DeleteAIAgents` API. |
