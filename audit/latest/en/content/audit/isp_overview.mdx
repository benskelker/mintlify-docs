This topic describes the functionality of the Audit space, part of the CyberArk Identity Security Platform Shared Services offering.

*   The Audit space is only available to users that have been assigned to the global auditor role in Identity Administration. For more information, see [Audit role](/identity-administration/latest/en/content/coreservices/getstarted/ispss-user-roles). If you don't have the Audit space tile in the navigator, contact your service administrator.

*   Do not change the global auditor name.

Introduction
--------------------------

The Audit space provides audit trails for activities, events, and sessions that are performed by any integrated service on the Shared Services platform.

An audit trail records system activities and helps track changes for purposes such as security, regulatory compliance, incident-response investigation, and troubleshooting.

Audit events may take several minutes to appear in the Audit space after the related system activity occurs.

How is an audit trail useful?
------------------------------------------

An audit trail is essential for several key activities that support organizational integrity, security, and compliance:

| Function | Organizational benefit |
| --- | --- |
| Detect and prevent fraud | Helps identify and investigate potentially fraudulent activities by providing a detailed record of who performed which actions, when, and how. |
| Meet regulatory requirements | Enables compliance with industry regulations and standards that require organizations to maintain verifiable records of system activities. |
| Troubleshoot issues | Provides a chronological record of actions and events, helping to pinpoint the root cause of system errors or failures. |
| Improve system security | Reveals potential breaches and vulnerabilities, supporting the enhancement of security protocols and incident-response procedures. |
| Review user incident handling | Supplies critical information for investigating incidents and developing consistent, effective response protocols. |
| Track user activity | Offers transparency into user sessions and activities, allowing real-time monitoring and response to suspicious behavior. |

Audit space features and functionality
----------------------------------------------------

In the Audit space, you can view system events and activities across all services, as well as access a session monitoring view that provides live session recording and oversight of user sessions for supported services.

Audit has the following capabilities:

*   Centrally organizes system and user event data across CyberArk services

*   Provides advanced search and filter capabilities so users can easily find the required information

*   Creates activity reports in the Audit space that can be downloaded for offline review

*   Retains all system activity records for up to one year

*   Supports integration with external SIEM systems to export audit activity data
