This topic explains how to monitor and assess security alerts to improve threat management using tools to track detection insights, review alert trends, and respond effectively to security alerts. You can analyze the security alerts using the following:

*   Trends and insights - The dashboard offers a centralized view of security-related insights, including alerts by severity, response trends, and top alerted users by severity. This supports greater security observability and overall understanding of your environment, helping you make informed decisions and continuously refine your security posture.

*   Security alerts feed - The security alerts feed consolidates all alerts that have been detected by CyberArk, giving you a comprehensive view of potential identity threats within the CyberArk Identity Security Platform Shared Services. Each alert provides essential details, such as the nature of the threat and its severity, allowing you to evaluate and act quickly on threats.

*   Alert lifecycle - Alerts move through different statuses during their lifecycle. Pending and resolved reflect the actual state of the alert and are visible to all users. Users can filter alerts by these alert statuses. In contrast, New and updated are personalized indicators. They show whether an alert has changed since the user last refreshed the page. These local statuses help users track changes without affecting the alert’s actual state.

To configure the different types of alerts, alert and detection settings, see [Configure detections and responses](/identity-protection-space/latest/en/content/itdr/alerts/overview).
