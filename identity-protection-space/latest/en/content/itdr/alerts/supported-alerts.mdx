This section gives an overview of all the supported IT and workforce alerts, long with the types of responses available for each alert. Response types include recommended, configurable, automatic, and manual actions that can be taken based on the alert.

Recommended and configurable responses
----------------------------------------------------

Alerts are categorized as either recommended or configurable, allowing flexibility in detection and response.

Recommended responses

Recommended alerts are predefined to detect and respond to specific events. These alerts include default settings and basic configurations, ensuring immediate protection without additional setup.

Configurable responses

These responses can be customized to meet specific organizational policies. The available configurations include:

*   Enabling or disabling the alert

*   Adjusting severity levels

For anomalous sign-in and suspicious application access alerts, the system uses machine learning algorithms to calculate severity levels dynamically.

Automatic and manual responses
--------------------------------------------

You can configure each alert to initiate responses either automatically or manually.

*   Automatic responses are executed without user intervention when conditions are met.

    *   Automatic, based on the detection severity – The response runs automatically according to the severity level assigned to the detection.

    *   Automatic when severity is set to &lt;low or above&gt; – The response runs automatically only when the alert severity meets or exceeds the defined threshold.

*   You can initiate manual responses as needed.

By default, any automatic response can also be executed manually, ensuring flexibility to adapt to different operational needs.
