You can monitor system activities and user sessions for Threat Detection and Response in the Audit shared services.

For specific threat detection and response activities, see [Threat Detection and Response audit events](/audit/latest/en/content/audit/product-audits/isp-tdr-audit).

*   Each Audit entry includes a direct link to the associated alert, making it easy to trace the origin of actions or events.

*   To view all audit logs related to a specific alert, use the Correlation ID in the Audit filter. The Correlation ID contains the alert ID, allowing you to easily locate all related audit records.
