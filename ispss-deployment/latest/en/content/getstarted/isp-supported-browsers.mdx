This topic describes the browser support for ISPSS and any required configuration, along with the supported languages.

[](https://docs.cyberark.com/ispss-deployment/latest/en/content/getstarted/isp-supported-browsers.htm)Supported browsers
--------------------------------------------------------------------------------------------------------------------------------------

ISPSS supports the following browsers:

| Browser | Version |
| --- | --- |
| Apple Safari* | Latest available version |
| Google Chrome | Latest available version |
| Microsoft Edge (Chromium-based) | Latest available version |
| Firefox | Latest available version |

*Apple Safari employs a pop-up blocker, which needs to be configured to allow ISPSS. In the browser settings, go to Websites &gt;Pop-up Windows and add the ISPSS URL to prevent the pop-up blocker from requesting permission every time you want to access the platform.

[](https://docs.cyberark.com/ispss-deployment/latest/en/content/getstarted/isp-supported-browsers.htm)Supported languages
---------------------------------------------------------------------------------------------------------------------------------------

By default, the ISPSS user interface is displayed in English. Additional languages are available based on the CyberArk services enabled for your organization.

Available languages:

*   Arabic
*   Brazilian Portuguese
*   Chinese (Simplified)
*   Chinese (Traditional)
*   Dutch
*   French
*   German
*   Italian
*   Japanese
*   Korean
*   Polish
*   Portuguese
*   Russian
*   Serbian
*   Spanish
*   Swedish
*   Thai
*   Turkish
*   Vietnamese

To view or change your language preference, go to Account &gt; Personal Profile, and select a language from the Language drop-down list.
