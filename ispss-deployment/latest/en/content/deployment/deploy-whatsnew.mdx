### Prerequisite when installing Privilege Cloud PSM on Windows Server 2016

When installing or upgrading PSM on a Windows 2016 machine, SQLExpress is no longer installed as part of the PSM installation/upgrade package.

*   When installing PSM on a Windows 2016 server, before the installation step, download SQL server 2019 express and install it on the connector machine that is running the PSM service.
