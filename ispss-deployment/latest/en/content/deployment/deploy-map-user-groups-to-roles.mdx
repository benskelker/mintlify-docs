Users can access a specific CyberArk service only if assigned a role with access permissions to that service. Built-in roles are available per service to define the access levels for each user in that service. Roles can be assigned to a group of users or to a single user.

ISPSS roles are the most efficient way to assign access rights to multiple users, enforce adaptive MFA, deploy applications, provision users, and more.

All users should be assigned to at least one role.

For details about users and roles, see CyberArk Identity Security Platform Shared Services user roles.
