This topic describes how to add SIA to an existing operational ISPSS environment.

You may already have an operational ISPSS environment containing default SaaS services and optionally Privilege Cloud access. The following workflow describes the steps to add SIA as an alternative access solution to your existing environment.

Prepare your ISP environment and the connector machine
--------------------------------------------------------------------

To successfully add SIA to your environment, execute the following steps in the specified order. Ensure each step is completed fully before proceeding to the next step.

1.   Configure network ports and outbound allowlist firewall rules for SIA. See SIA connector machine requirements.

2.   Check connector machine specifications for hardware and software.
