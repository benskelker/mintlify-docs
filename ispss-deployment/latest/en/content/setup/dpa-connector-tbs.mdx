If there are errors during the installation of the SIA connector client, first verify that the system and network requirements are met. For more information, see System requirements and SIA network traffic requirements.

The connection client installation script is divided into several steps.

At the beginning of each step, a message is displayed on the screen to indicate this step is starting. If there is an error during the step, the next step's message is not displayed and instead an error message indicates the issue.
