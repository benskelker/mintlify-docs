The Identity Administration service manages all users and roles for the CyberArk services that are on ISPSS.

This section presents the workflow steps for adding and authenticating your users in Identity Administration and assigning them the required permissions to access and use CyberArk services on ISPSS.

Identity Administration prerequisites
---------------------------------------------------

Ensure you have performed all Identity Administration preparatory steps described in [Prepare your environment](/ispss-deployment/latest/en/content/deployment/deploy-prepare-your-environment).

Access Identity Administration
--------------------------------------------

Access Identity Administration [through the CyberArk ISPSS portal](/ispss-deployment/latest/en/content/ispss/ispss-collect-login-and-setup-details).

Add users and roles
---------------------------------

Following are the main steps for adding and managing users and roles.

*   [Add users](/identity-administration/latest/en/content/ispss/ispss-provision-users)

*   [Set up federation with external identity providers](/identity-administration/latest/en/content/coreservices/usersroles/partnersetup) (optional)

*   [Provision users to the CyberArk Cloud Directory with SCIM](/identity-administration/latest/en/content/coreservices/usersroles/provision-with-scim) (optional)

*   [Configure MFA for Identity Administration](/identity-administration/latest/en/content/getstarted/security-fundamentals)

Multi-factor authentication applies to shared services on ISPSS, excluding Secure Cloud Access and Cloud Entitlements Manager
*   [Assign users to roles and manage roles](/identity-administration/latest/en/content/coreservices/getstarted/userrolesassign)

*   [Invite users](/identity-administration/latest/en/content/getstarted/invite-users)

For all user management capabilities, see [Identity Administration documentation](/identity-administration/latest/en/content/coreservices/core-overview).
