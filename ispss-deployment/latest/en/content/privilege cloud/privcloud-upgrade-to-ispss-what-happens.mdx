This topic explains the changes in architecture, interfaces, and user management that occur when upgrading to the ISPSS environment.

[](https://docs.cyberark.com/ispss-deployment/latest/en/content/privilege%20cloud/privcloud-upgrade-to-ispss-what-happens.htm)What's new in the ISP environment architecture
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

The following diagram presents the architecture of Privilege Cloud on Shared Services. It is similar to the Privilege Cloud Standard architecture you have today, highlights the new services and components that are added to the system setup, and explains changes in the interface between your organizational environment and the CyberArk cloud:

Changes in architecture when upgrading to the ISPSS environment| Component | Description |
| --- | --- |
| Identity Administration portal | New web portal in the CyberArk Shared Services environment, used by admins to manage users and user permissions. Replaces the Privilege Cloud Portal user management function. |
