This section includes REST APIs for CyberArk's Bring your own key (BYOK) solution, using AWS KMS encryption keys.

CyberArk BYOK supported services include:

*   Privilege Cloud

*   EPM

For information about CyberArk's BYOK functionality and how to use it, see [Bring your own key (BYOK) for data encryption](/ispss-deployment/latest/en/content/privilege cloud/privcloud-byok-intro).

### Before you begin

Prior to calling ISPSS REST APIs, learn about the required ISPSS URLs, how to set up a service user, and how to generate the authorization token. See [API Authentication for CyberArk Identity Security Platform Shared Services](https://api-docs.cyberark.com/create-api-token/docs/create-api-token).
