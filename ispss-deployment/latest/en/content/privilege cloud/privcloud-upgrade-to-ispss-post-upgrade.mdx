Your CyberArk users have been moved to the CyberArk Identity Security Platform Shared Services, where they can be viewed and managed in the Identity Administration user portal.

CyberArk sends you a notification email that the upgrade has been completed, and requests that you perform the following finalization steps:

#1 Sign in to Identity Administration
---------------------------------------------------

1.   Sign in to the ISPSS user portal using the link https://&lt;subdomain&gt;.cyberark.cloud and initial user provided in the CyberArk email. Note that [the initial user password was updated in the pre-update steps](/ispss-deployment/latest/en/content/privilege cloud/privcloud-upgrade-to-ispss-setup-ispss).The Privilege Cloud Portal opens automatically.

2.   Click the navigator and select Identity Administration.

The navigator also enables access to all other shared services

#2 Check and adjust user roles
--------------------------------------------

As part of the upgrade, all your users that are assigned to predefined LDAP groups are assigned to relevant user roles in Identity Administration, according to the role mapping performed in the planning stage. Users may also have manually assigned permissions, and these will result in additional roles assigned to that user.

1.   After the upgrade, access Identity Administration and check user role assignment to verify users have the necessary user permissions.

2.   After the upgrade, you may need to re-assign permissions that were defined manually before the upgrade.

3.   Roles are not only assigned per LDAP user group but also specifically per each user. Therefore, when removing a user from a specific LDAP group, access Identity Administration and manually remove the specific role from the user, to cancel the related permissions.

To learn about user roles and how to manage them:

*   See [Check user roles](/ispss-deployment/latest/en/content/privilege cloud/privcloud-upgrade-to-ispss-check-roles).

#3 Request CyberArk cloud directory users (local users) to reset their password
---------------------------------------------------------------------------------------------

As part of the upgrade, the CyberArk local users that were originally defined in your Privilege Cloud Standard system have been  upgraded to the new Privilege Cloud ISPSS, where they are now defined as CyberArk cloud directory users. However, the following scenarios may occur:

*   Users were not defined with their email address. Ensure all CyberArk cloud directory users have a correct and updated email address.

*   Due to security considerations, users are now defined in the system without a password, and are required to reset their password.

Before handling CyberArk cloud directory users, view the following video to learn about the CyberArk cloud directory.

Request CyberArk cloud directory users to reset their password:

1.   In Identity Administration, access Core Services&gt;Users and check the Users list for the following users types:

    *   Source column: displays CyberArk Cloud Directory users

    *   Email column: is empty

The upgrade may have caused the addition of a suffix to the user name, so that it is now JohnDoe@[identitydomain].com. This is now the formal name of the user in the ISPSS environment.

2.   Check the roles assigned to the CyberArk cloud directory users during the  upgrade, and verify each user has a correct email address.

For each user:

    *   Click the user to access the user's details and add the relevant email address.

    *   Click Roles to check the Privilege Cloud role assigned to the user. See [Users' Privilege Cloud roles in ISPSS](/ispss-deployment/latest/en/content/privilege cloud/privcloud-upgrade-to-ispss-diff)

    *   Click Save to save all changes and return to the user list.

3.   Invite the CyberArk cloud directory users.

In the Users list, sort the Status column and review all users that display Not Invited. Select the checkbox of each Not Invited user and select Actions&gt;Send email invite for user portal setup.

3.   On the Authenticate to Privilege Cloud page, enter the Customer ID provided to you in the Welcome to CyberArk Identity Security Platform email and the installeruser name (installeruser@&lt;suffix&gt;)
