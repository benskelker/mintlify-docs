This section describes the common enterprise use cases that require security-first access management controls according to the CyberArk Blueprint.

Security-first access management capabilities include single sign-on, passwordless authentication, adaptive multi-factor authentication, web session protection, session auditing, and secure browsing controls.

Use cases include:

Identity Security Platform

IT Security Tools

IT Automation Tools

CI/CD Consoles

Web Applications (Mission-Critical)

Corporate Social Media

Web Applications (Core)

Workforce Credentials (Non-Enterprise Web Apps)

Web Applications (All)
