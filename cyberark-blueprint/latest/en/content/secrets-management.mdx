This section describes the common enterprise use cases that require secrets management controls according to the CyberArk Blueprint.

Secrets management capabilities include secrets vaulting and rotation, workload authentication, just-in-time secret retrieval, and auditing controls.

Use cases include:

Identity Security Platform Automation

IT Security Tools

IT Automation Tools

Cloud Native Workloads

CI/CD Pipeline

Dynamic Applications (Containerized Environments)

On-Prem and Lift & Shift Applications

COTS Applications

Windows Services (Embedded Usages)

IoT/OT
