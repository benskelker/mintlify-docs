This topic discusses how identity security integrates into various pillars of an enterprise information security program.

Enterprise information security program management typically consists of a variety of different pillars, often owned by different security leaders, all rolling up to a CISO-type role. These information security programs typically include areas of cybersecurity such as identity access management (IAM), privileged access management (PAM), threat detection and response, vulnerability management, endpoint security, DLP and data privacy, network security, governance risk and compliance (GRC), application security (AppSec) and business continuity disaster recovery (BCDR), among many others .

As you build out your identity security program and operating model, it’s important to understand how identity security fits into this typical enterprise program management model. Identity security is so interlinked with many of these enterprise security programs that it becomes part of the fabric of your security. Identity security typically spans across IAM, PAM, endpoint security, application security, threat detection and response, and governance risk compliance.

Within traditional IAM program management, identity security provides identity governance and security-first access management controls, which enable your organization to control and govern access to enterprise resources via the identity security control plane and deliver underling and foundational access to enterprise web applications and systems.

Within PAM, endpoint security, and application security, identity security offers intelligent privilege controls. These controls help protect your workforce, IT, developer, and machine identities by securing high-risk and sensitive enterprise resources, removing local admin rights from endpoints, protecting browser and credential stores, and eliminating hard-coded secrets from machine workloads.

You can improve threat detection and response programs with identity security intelligence capabilities that provide proactive and reactive response to identity-related threats at a wider scope than traditional ITDR solutions.

You can bolster governance risk and compliance programs through audit and reporting capabilities that illustrate the risk mitigation progress and compliance efforts.
