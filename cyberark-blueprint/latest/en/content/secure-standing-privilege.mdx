This section describes the common enterprise use cases that require secure standing privilege controls according to the CyberArk Blueprint.

Secure standing privilege capabilities include credential vaulting, credential rotation, enforcement of credential and session isolation, auditing, monitoring, and the principle of least privilege controls.

Use cases include:

Domain Admins

Windows Server Admin (Local)

Windows Workstation Admin (Local)

MacOS Workstation Admin (Local)

*NIX Root + SSH Keys

Hypervisor Consoles

Cloud Service Providers (Root and Registration Accounts)

Cloud Service Providers Directory Users and Keys (Local)

Database Built-In Admins

Workstation Admins (Domain)

Network and Infrastructure Admins

Out of Band Access

Mainframe Administrators

Client-Based Applications
