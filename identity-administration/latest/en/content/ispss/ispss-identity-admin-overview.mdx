Identity Administration serves as the centralized user management function of CyberArk Identity Security Platform Shared Services, a unified platform for CyberArk's SaaS services. Identity Administration provides a single centralized interface for provisioning users and setting up the authentication for users of the Shared Services platform.

About CyberArk Identity Security Platform Shared Services
-----------------------------------------------------------------------

CyberArk Identity Security Platform Shared Services delivers unified administration and end user experience across CyberArk's access management, privileged access management and identity management solutions.

The Shared Services platform includes Identity Administration, Audit and Identity Security Intelligence.

The platform allows secure access to CyberArk SaaS services based on role-based users and permissions, and offers a centralized display and user experience, while leveraging built-in single sign-on, multi-factor authentication and Lifecycle management. These shared services enable operational efficiencies for administrative processes using CyberArk solutions, deliver measurable cyber-risk reduction for all identities and satisfy audit and compliance with centralized processes. The administrative functions, covering user provisioning, authentication and access permissions are all managed within the Identity Administration User Portal.

Currently, the shared services are integrated with Privilege Cloud, Identity Administration, Dynamic Privileged Access and Cloud Entitlements Manager.

About Identity Administration
-------------------------------------------

Identity Administration enables administrators to:

*   Authenticate users from external directory services or CyberArk's Cloud directory

*   Authorize role-based access to the various CyberArk services

*   Apply policies to determine specific access and functional permissions

*   Generate reports to track user, application and device behaviors for cross-service security and audit purposes
