This topic describes how to enable web applications so that Workforce Password Management (WPM) can get credentials from a Safe in Privilege Cloud or PAM - Self-Hosted. When you sign in to the application, WPM retrieves your credentials from a Safe, then auto-fills those credentials into the application. Auto-fill can happen when you do either of the following:

*   Open the application in the User Portal.

*   Add the application to the User Portal using Land & Catch.
