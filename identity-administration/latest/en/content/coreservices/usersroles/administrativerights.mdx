Administrative rights enable access to services or functionality. The following tables describe the administrative rights you can assign to a role.

If you attempt to perform a task for which you do not have the necessary administrative right, you will see an error message. In addition, you can only see data that is pertinent to your administrative rights. For example, if you only have the Application Management right, you are not allowed to change policy settings.

Some administrative rights also grant reporting rights, but only for data that the user has been granted rights to read.

Activities and Recordings administrative rights
-------------------------------------------------------------

See the [Audit documentation](/audit/latest/en/content/audit/isp_overview) for more information.

Activities and Recordings administrative rights| Administrative right | Description |
| --- | --- |
| Show Audit Service Tile | Show the Audit service in the navigator. |

Administration space administrative rights
--------------------------------------------------------

See the [Administration space documentation](/admin-space/latest/en/content/admin-get-started/as-manage-users) for more information about the space.

Rights marked with *are included in the Administration role by default.

Administration space administrative rights| Administrative right | Description |
| --- | --- |
| Show Administration space Tile* | Show the Administration space in the navigator. |
| Full permissions for the domain customization capability* | Full permissions for the domain customization capability. |
