This topic describes the regions that CRDR supports during a CRDR incident.

CRDR supported regions
------------------------------------

Each main site is paired with a designated Disaster Recovery (DR) site. CRDR keeps the main site and DR site synchronized, continuously replicating identities, permissions, and secrets.

The following regions are supported:

| Main site | Disaster Recovery (DR) site |
| --- | --- |
| us-east-1 (N. Virginia) | us-west-2 (Oregon) |
| eu-central-1 (Frankfurt) | eu-north-1 (Stockholm) |
| eu-west-2 (London) | eu-west-1 (Ireland) |
