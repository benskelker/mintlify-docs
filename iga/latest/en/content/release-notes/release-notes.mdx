This topic provides a running list of release notes for CyberArk IGA, including enhancements, new features, and resolved issues for each release.

February 11, 2026 release (26.2.3)
-----------------------------------------------

### Provisioning Update

CyberArk IGA now enables you to configure provisioning and deprovisioning lifecycle actions for SaaS applications with REST APIs directly in the user interface. This provides easier, more accurate, and consistent management over access changes in business applications that support REST-based integration.

### Access review campaign update

CyberArk IGA now includes the Permission Structure Review access review type that introduces a structured way to validate and attest to permission-granting models before running user access review campaigns.

This capability enables organizations to review roles, groups, profiles, and permission sets to confirm that the access each permission structure provides is appropriate, complete, and aligned with current policies. Permission models vary across organizations do reviewing these structures first ensures accuracy and consistency.

By certifying permission structures in advance, reviewers can focus user access reviews solely on whether user membership is appropriate. This approach supports stronger governance and audit readiness by enabling regular, evidence-based reviews of permission structures before evaluating user access assignments.

### Integration update

CyberArk IGA now provides a connector to integrate with CyberArk PAM Privilege Cloud. This integration:

*   Discovers all safes and related metadata from Privilege Cloud.

*   Evaluates and resolves user, role and group assignments to safes for permission structure and access reviews.

*   Provides complete visibility of who has direct and indirect access to each safe.

This integration currently supports up to 2,500 safes. If your deployment has more than 2,500 safes, contact your account team to find a solution with product management.

October 13, 2025 release (25.10.2)
-----------------------------------------------

### Provisioning update

*   CyberArk IGA now includes enhancements to the IGA integrated apps that let users override account properties and map user metadata to collect and display custom attributes.

*   CyberArk IGA now provides out-of-the-box provisioning capabilities for the following integrations: GitHub, Google Cloud Platform (GCP), AWS Organizations, Jira, ServiceNow, Snowflake, and CyberArk Identity. September 22, 2025 release (25.9.4)
------------------------------------------------

### Integration update

CyberArk IGA now provides improved handling of service principals when integrating with Microsoft Entra ID and Azure Cloud Subscriptions.

When Discover Child Apps is enabled, the integration:

*   Captures the Display Name as the Account Name.

*   Includes Scope with permissions in the format RoleName:Scope

*   Syncs the Account Type as Service

These updates ensure consistent parent-child application structures.
