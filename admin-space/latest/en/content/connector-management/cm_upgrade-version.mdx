This topic describes how to set the upgrade version for Management Agent upgrades. How this version is used depends on the Management Agent automatic upgrade setting:

*   Automatic upgrade set to On: The Management Agent automatic upgrade uses the configured upgrade version. For more information, see [Management Agent automatic upgrade](/admin-space/latest/en/content/connector-management/cm_auto-upgrade-connector).

*   Automatic upgrade set to Off and upgrade version set to N: You can manually upgrade the Management Agent to version N.

*   Automatic upgrade set to Off and upgrade version set to N-1: You can manually upgrade the Management Agent to version N or N-1.
