This topic describes how to automate upgrades of the Management Agent and keep your environment up to date. When you configure and enable this capability, the Management Agent automatic upgrade automatically detects when a new Management Agent version is available and upgrades the version in the background, without any user action. This reduces maintenance effort and helps ensure consistent Management Agent versions across all managed connectors.

The Management Agent automatic upgrade uses the configured version, as described in [Management Agent upgrade version](/admin-space/latest/en/content/connector-management/cm_upgrade-version).

*   You can use this capability only after manually installing Management Agent version 2.0.839 or later.

*   You do not have to use this capability. You can continue manual upgrades, as per your specific requirements.

Before you begin
------------------------------

*   Review current automatic upgrade settings, such as preferred version and maintenance window.
