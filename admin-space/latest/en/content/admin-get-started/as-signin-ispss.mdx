This topic describes the onboarding experience for first-time users of ISPSS. Administration is accessed via CyberArk's Identity Security Platform Shared Services (ISPSS). ISPSS is a platform that provides a unified admin and end user experience for CyberArk customers.

If you are new to ISPSS, you will receive a welcome email to CyberArk's ISPSS. The email contains a link to your ISPSS cloud tenant, access credentials, and your tenant ID. On your first sign-in, you are prompted to set a password. Once you sign in, you can add users as members to the Administration role. Only members can see and access Administration from the navigator.
