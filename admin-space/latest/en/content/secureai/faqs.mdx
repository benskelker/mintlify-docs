Onboarding and registration
-----------------------------------------

Problem - I can’t find the Redirect URL for my agent.

Cause - For predefined agents (such as Copilot or Claude), the Redirect URL is managed internally by CyberArk for security reasons and is not displayed.

Solution - You do not need to enter a Redirect URL for predefined agents. This field is only shown and required if you select Custom as the Agent Type.
