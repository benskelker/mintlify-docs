This topic contains the REST APIs that you use to manually add and manage Microsoft Entra tenant s and subscriptions.

Before you use APIs to add Microsoft Entra tenant s and Azure subscriptions, make sure that you have the required permissions. For more information, see [Azure resources and required permissions](/admin-space/latest/en/content/cce/azure/azure-resources).
