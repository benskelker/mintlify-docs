This topic describes how to view and resolve issues that may occur with your Microsoft Entra tenant s or subscriptions.

[](https://docs.cyberark.com/admin-space/latest/en/content/cce/azure/azure-resolve-entity-issues.htm)View and resolve Azure entity issues
-------------------------------------------------------------------------------------------------------------------------------------------------------

If an issue is encountered during the resource deployment in Azure, the subscription or Entra tenant will be flagged as Needs attention.

To view all Microsoft Entra tenant s, management groups, or subscriptions that need attention, in the Filter pane, select Entities that need attention.

1.   Click the Needs attention link that appears on the subscription or Microsoft Entra tenant line.

The Azure entities issues page appears.

2.   For each issue, review the issue information and the steps to resolve the issue.

3.   After you have resolved the issue, make sure to click resolved.
