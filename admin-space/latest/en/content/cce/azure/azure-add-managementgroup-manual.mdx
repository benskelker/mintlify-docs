title: "Add an Azure management group manually"
description: "This topic describes how to manually add an Azure management group to the CCE environment and deploy service resources in the Azure Cloud Shell."
---

This topic describes how to manually add an Azure management group to the CCE environment and deploy service resources in the Azure Cloud Shell.

If you are migrating existing cloud entities from a CyberArk service, you must delete the service resources from the cloud environment before adding them to CCE.

When you add a management group, all the subscriptions in the management group are also added.
