This topic describes how to view and resolve issues that may occur with your AWS organizations or accounts.

[](https://docs.cyberark.com/admin-space/latest/en/content/cce/aws/aws-resolve-entity-issues.htm)View and resolve AWS entity issues
-------------------------------------------------------------------------------------------------------------------------------------------------

If an issue is encountered during the resource deployment in AWS, the single account or organization will be flagged as Needs attention.

To view all single accounts or organizations that need attention, in the Filter pane, select Entities that need attention.

1.   Click the Needs attention link that appears on the single account or organization line.

The AWS entities issues page appears.

2.   For each issue, review the issue information and the steps to resolve the issue.

3.   After you have resolved the issue, make sure to click resolved.
