The section contains end-to-end AWS standard API workflows for adding organizations and single accounts, and managing the connected entities using either the CloudFormation template or Terraform.

To view the APIs, see[AWS standard APIs](/admin-space/latest/en/content/cce/aws/aws-api-standard).

Before you use APIs to add AWS organizations and accounts, make sure that you have the required permissions. For more information, see [AWS required permissions](/admin-space/latest/en/content/cce/aws/aws-resources).

Overview
----------------------

Using APIs, you can perform the following actions to organizations:

*   Add organizations

*   Add services to an organization

*   Get organization details

*   Get organization hierarchy

*   Remove services from an organization

*   Delete an organization

Using APIs, you can perform the following actions to accounts:

*   Add an account as a separate entity

*   Get account details

*   Get a list of single accounts

*   Add services to an account

*   Remove services from an account

*   Delete an account
