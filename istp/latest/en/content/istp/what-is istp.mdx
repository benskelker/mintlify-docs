CyberArk's Identity Security Terraform Provider transforms how your organization can manage identity security.

Overview
----------------------

[Terraform](https://developer.hashicorp.com/terraform) is a leading Infrastructure-as-Code (IaC) tool that automates the deployment and management of IT infrastructure (like servers, networks, and cloud services).

By enabling teams to define and automate CyberArk configurations as Infrastructure as Code (IaC), it delivers consistent security, reduces operational risk, and accelerates deployment speed across all cloud and on-premises environments.

This solution ensures that identity and access controls scale securely alongside your critical infrastructure, maintaining full auditability and least-privilege control at every step.

Get started
-------------------------

The Identity Security Terraform Provider is available in the Terraform public registry.

For requirements and setup information, see the relevant[Terraform provider documentation](https://developer.hashicorp.com/terraform/install).

### [](https://docs.cyberark.com/istp/latest/en/content/istp/what-is%20istp.htm)Supported Terraform versions

The Terraform public registry-based provider requires Terraform 0.13.x or later.
