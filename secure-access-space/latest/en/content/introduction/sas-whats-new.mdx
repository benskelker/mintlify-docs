### Upcoming change: Enforced reason prompt for Show Password and SIA access

The Secure Access space and Secure Infrastructure Access (SIA) will soon enforce a consistent reason prompt when user access requires justification.

When the Require users to specify a reason for access master policy is enabled in Privilege Cloud, users must manually enter a reason before access is granted. Automatically pre-filled reasons are no longer supported.

This enforcement applies consistently to the following access methods:

*   Showing passwords in the Secure Access space

*   SIA connections initiated through the Secure Access space (RDP and SSH)

*   Native SIA connections (RDP and SSH)

*   Access through the SIA API (RDP and SSH)

This change captures a clear, user-provided justification, regardless of how users perform access, which improves governance and auditability.
