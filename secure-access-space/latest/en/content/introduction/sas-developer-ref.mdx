This section includes the following APIs for the services in the Secure Access space.

*   [Secure Access API](https://api-docs.cyberark.com/secure-access/docs/secure-access-api): View and securely access your assets

*   [Access request APIs](/secure-access-space/latest/en/content/cloud-consoles/ar-apis): View and manage access requests

The Secure Access REST API documentation describes the operations that can be performed for Secure Access programmatically. For more information about CyberArk REST APIs, see [CyberArk API docs](https://api-docs.cyberark.com/).
