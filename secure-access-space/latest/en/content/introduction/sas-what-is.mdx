The CyberArk Secure Access space enables you to manage and access your organization's cloud and infrastructure resources in a web-based environment. It integrates seamlessly with your CyberArk deployment, offering a more unified user experience.

The Secure Access space enables you to access assets secured in the CyberArk Privilege Cloud via the Secure Infrastructure Access (SIA) component. The space also enables you to view and copy credentials and it affords zero standing privileges access to your organizational infrastructure.

The Secure Access space lets you access cloud services protected with the Secure Cloud Access (SCA) solution, and to manage and launch web applications via CyberArk Identity single sign-on (SSO).

Solution benefits
-------------------------------

The Secure Access space provides the following benefits:

*   Centralized management - You can effortlessly connect and manage all your targets, applications, devices, and cloud resources from a single, intuitive interface, thus reducing complexity and saving time.

*   Unified user experience - The space delivers a consistent and user-friendly experience that makes it easy to connect to and manage diverse resources.

Workflows
-----------------------

The following table describes the Secure Access space workflows.

| Workflow | Description |
| --- | --- |
| Access certification | You can certify or revoke user access to resources during an identity certification campaign, which enables your organization to define and run a periodic review of the access a group of users have to various resources. For more information, see [Certify user access](/secure-access-space/latest/en/content/access-certification/certify-a-campaign). |
| Apps and secured items | You can manage, add, and launch web apps and share credentials to your business applications with other users. You can also request access to applications for single sign-on in the Secure Access space, as well as grant access to an application if you are a designated approver. For more information, see [Manage apps and secured items](/secure-access-space/latest/en/content/apps-and-secured-items/apps-and-secured-items). |
| Infrastructure | You can securely access your infrastructure resources, such as cloud workspaces, databases, and virtual machines, that you use in your work. For more information, see [Access infrastructure resources](/secure-access-space/latest/en/content/infrastructure/sas-inf-lp). |
| Cloud consoles | You can securely access your cloud console, request elevated privileges for a console you already have access to, or request on-demand access to a console you cannot yet access. For more information, see [Access cloud consoles](/secure-access-space/latest/en/content/cloud-consoles/sas-cloudconsoles-lp). |
| Request application access | You can request access to web apps for single sign-on in the Secure Access space. If you are a designated approver, you can also review and grant access to applications. For more information, see Request access to applications. |
