This topic describes how to use folders in Workforce Password Management (WPM) to better organize business applications and frequently used secured items. For example, you can group all of your banking applications and related notes together in the same folder.

[](https://docs.cyberark.com/secure-access-space/latest/en/content/apps-and-secured-items/manage-folders.htm)Create folders
-----------------------------------------------------------------------------------------------------------------------------------------

You can create up to 100 folders.

1.   In the Secure Access space, click Add and select Folder.

If you do not see Folders in the dropdown, your administrator has disabled folders.

2.   Enter a name and description.

Folder names may not contain `&lt;`, `&gt;`, `\`, `\{`, `\}`, or the character combination `&#`.

This restriction is checked when you create or update a folder using the UI, API, or import workflow.
3.   Click Save.

Add applications or secured items to a folder
-----------------------------------------------------------

You can add up to 1000 secured items and applications to one folder. You might group together items of the same type, organize frequently used items, and so on.

You cannot add items to a folder if your administrator has restricted access to those items.

Two methods are available for adding items to folders: drag and drop and the Settings dialog box.

### Drag and drop items to a folder

To add an application or secured item to a folder, drag and drop the item to the folder. You can drag and drop only one item at a time.

### Use the Settings dialog box

The Settings dialog box offers two advantages:

*   You can add an application or secured item to multiple folders at the same time.

*   You can add items to a folder that was not previously created. The folder is created when you save the changes.

To add an application or secured item to a folder:

1.   In the Secure Access space, find the tile for the application or secured item that you want to add to a folder.

2.   On the tile, click the More options button to open the Settings dialog box.

3.   In the Add to folder field, specify one or more folder names. If the folder does not yet exist, it is automatically created.

4.   Click Save.
