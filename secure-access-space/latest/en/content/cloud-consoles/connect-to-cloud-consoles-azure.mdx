This topic describes how to connect to Azure or join an Entra group securely via SCA. Use any of the following methods to connect, based on whether you want to elevate your privileges for this work session or use your current permissions.

*   [Azure console](/secure-access-space/latest/en/content/cloud-consoles/connect-to-cloud-consoles-azure)
*   [Azure CLI](/secure-access-space/latest/en/content/cloud-consoles/connect-to-cloud-consoles-azure)

If you want to access the Azure console with your current permissions, click the link in the instructions to connect directly to the console instead of via the options available in the table.

To connect to the Azure console and join Entra groups:

1.   Sign in to the Secure Access space.

2.   In the Applications page, click the relevant Azure web app tile.

If you don't see an Azure web app, you can request on-demand access. To request on-demand access, see [Request on-demand access to cloud services](/secure-access-space/latest/en/content/cloud-consoles/request-temporary-cloud-access).

On-demand access is not supported for Entra group assignments.
3.   In the Azure resources page, find the scope that you want to access (directory, management group, subscription, resource group, or resource), click Select permissions.

4.   A list of roles you can connect to Azure with and Entra groups you can join is displayed.

Select the Azure roles you want to connect to Azure with and/or select the Entra groups you want to join, and click to connect and/or join the Entra groups.

If you selected only roles, you are connected to the Azure portal with the roles you selected.

If you selected only Entra groups, you are assigned to those groups

A message displays the statuses of the connections and Entra groups assignments.
