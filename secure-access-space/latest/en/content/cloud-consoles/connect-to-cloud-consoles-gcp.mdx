This topic describes how to connect to the Google Cloud console securely via SCA. You have two options for connecting, based on whether you want to elevate your privileges for this work session or use your current permissions.

*   [Google Cloud console](/secure-access-space/latest/en/content/cloud-consoles/connect-to-cloud-consoles-gcp)
*   [Google Cloud CLI](/secure-access-space/latest/en/content/cloud-consoles/connect-to-cloud-consoles-gcp)

If you want to use the Google Cloud console with your current permissions, click the link in the instructions to connect directly to the console instead of via the options available in the table.

To connect to the Google Cloud console:

1.   Sign in to the Secure Access space.

2.   In the Applications page, click the relevant Google Cloud web app tile.
