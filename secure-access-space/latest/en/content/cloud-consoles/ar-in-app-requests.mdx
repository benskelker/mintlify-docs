This section describes how to manage on-demand access requests to cloud consoles.

This section contains content relevant to the person making access requests and the person designated as an approver for these requests.

*   Cloud consoles - You can manage on-demand access to cloud consoles in the Secure Access space if Secure Cloud Access (SCA) has been configured to work using the CyberArk in-platform approval channel.

For more information about setting up the CyberArk in-platform approval channel in SCA, see Set up on-demand access.
