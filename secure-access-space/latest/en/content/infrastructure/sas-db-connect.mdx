This topic describes how to connect to a database target using zero standing privileges (ZSP) from the Secure Access space in ISPSS. This topic also describes other tasks you can perform on the page.

For information about the supported databases, see [Supported databases](/secure-access-space/latest/en/content/infrastructure/sas-db-connect).

[](https://docs.cyberark.com/secure-access-space/latest/en/content/infrastructure/sas-db-connect.htm)Before you begin
-----------------------------------------------------------------------------------------------------------------------------------

*   You must have SIA to use the Secure Access space.

*   This capability must be enabled by your ISPSS admin for you to see it in the navigator. For details, see Give end users access to the Secure Access space.

*   You must have a valid authentication token, which keeps you securely logged in for a set time period so you don't have to verify your identity every time you connect. This period is configured by your admin.

When connecting to a database, if you do not have a valid token, you are prompted to generate a new one. You can create either a password or client certificate for databases, depending on the database type. For connections to Oracle databases, you can generate an Oracle wallet.
