This topic describes how to connect to a Windows target using vaulted credentials or zero standing privileges (ZSP) from the Secure Access Infrastructure page in ISPSS. This topic also describes other tasks you can perform on the page.

[](https://docs.cyberark.com/secure-access-space/latest/en/content/infrastructure/sas-windows-connect.htm)Before you begin
----------------------------------------------------------------------------------------------------------------------------------------

*   You must have SIA to use the Secure Access space.

*   This capability must be enabled by your ISPSS admin for you to see it in the navigator. For details, see Give end users access to the Secure Access space.

Add an unlisted Windows target
--------------------------------------------

This procedure describes how to manually add a target to the list on the Secure Access Infrastructure page. Before you can connect to targets with vaulted credentials in PAM - Self-Hosted or those accessed with ZSP, you must manually add them to the list.
