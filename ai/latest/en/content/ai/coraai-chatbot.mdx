"Hi, I'm CyberArk's AI chatbot"

CyberArk's CORA AI chatbot transforms the way you interact with the CyberArk Identity Security Platform Shared Services. With CORA AI capabilities, you can query data from your CyberArk environment or perform actions that bolster your identity security program outcomes. As a conversational interface, the CORA chatbot enables you to engage with CyberArk's services through natural language. It can understand your queries, provide context-relevant information, and run commands to assist in performing your tasks. The CORA chatbot helps you navigate the complexities of identity security and simplifies your daily tasks.

CyberArk's CORA AI chatbot uses Azure OpenAI as the Gen AI tool. You can read more about CyberArk's commitment to [Responsible AI](https://www.cyberark.com/trust/responsible-ai/).

This capability is currently available in a few shared services and will gradually be available in additional ISPSS services. CyberArk CORA AI may be subject to updates and improvements over time.

Features and benefits
-----------------------------------

The CORA AI chatbot offers a suite of features that enhance your interaction with the Identity Security Platform.

Natural language processing capabilities are integrated into CyberArk's AI chatbot, enabling it to comprehend your queries in regular language phrases. There's no need for you to memorize specific commands or syntax; just write to the chatbot as you would to a colleague.

You can perform the following interactions:

*   Ask questions: Ask the CORA AI chatbot about details specific to your environment, such as details about Safes within a certain platform or who has access to a specific Safe - the CORA AI chatbot will provide the answers.

CORA AI chatbot answers your questions based on the contents found in the [official CyberArk knowledge sources](/ai/latest/en/content/ai/coraai-introduction).

*   Perform tasks: The CORA AI chatbot can perform various tasks on your behalf, such as managing accounts and Safes, approving access requests, and retrieving platform information. It is designed to save you time and effort, making those repetitive tasks easier and quicker to perform.

The CORA AI chatbot focuses on service approachability and ease of use. This is key to extending identity security to a wider audience. Whether you're a seasoned professional or new to cyber security, the CORA AI chatbot ensures that you find what you need quickly and efficiently.

The CORA AI chatbot streamlines your interactions with CyberArk, enhances your user experience, and helps you navigate the complex world of identity security with ease.

Scope
-------------------

The CORA AI chatbot is available in the Privilege Cloud, Identity Administration, and Audit services. It is available to users who are assigned to specific user roles and supports the following use cases:

Service-integrated AI chatbot| Service | CORA AI chatbot supported actions and user roles |
| --- | --- |
| Privilege Cloud AI | * Account and Safe management: Assists you in adding new Safes, managing members within your Safes, or adding accounts. These tasks are fundamental to maintaining the security and organization of your privileged accounts. Privilege Cloud * Providing information on existing target platforms: Provides any platform details that you request. * Managing pending access requests: Manages and streamlines the process for pending access requests, ensuring efficient access control. For more information, see details about the queries supported in [Privilege Cloud](/privilege-cloud-shared-services/latest/en/content/privilege cloud/privcloud-cora-ai-bot). Supported Privilege Cloud user roles: * Privilege Cloud Administrators Basic * Privilege Cloud Administrators Lite * Privilege Cloud Safe Managers Basic * Privilege Cloud Safe Managers Lite * Privilege Cloud Safe Managers |
| Audit AI | * Queries on audit data: Facilitates queries about audit data that is available in the central Audit service. Currently, this includes data from Dynamic Privileged Access, Secure Cloud Access, Secrets Hub, and Secrets Manager - SaaS. * Filtering and extracting reports: Assists in filtering audit data and extracting reports, making it easier for you to analyze it and make informed decisions. For more information, see details about the queries supported in [Audit](/audit/latest/en/content/audit/audit_cora-ai-bot). |
| Identity Administration AI | Manage identities and access: Helps you add new cloud users, modify existing user information, manage roles and members, and send email invitations to users. Query existing target platforms: Provides details on policies, password complexity, role members, user login times, role attributes, and more. For more information, see details about the identities and access managed and the queries supported in Identity Administration. Supported Identity Administration user role: * System Administrator |

### Manage your chats

Interacting with the CORA AI chatbot is managed through the user interface:

Chat interaction options| Service | Description |
| --- | --- |
| Start a new chat | From the menu at the top, select Start a new chat to start a new conversation or clear the previous conversation. |
| Get a chat suggestion | Not sure how to start the conversation? Select one of the provided prompts to perform a popular action. |
| Confirm an action | Before it performs a request, the CORA AI chatbot requires you to review and confirm it. Respond with a Yes or a No to complete the request. |
| View chat history | During a single authenticated session, you can access the chat history. Keep in mind that initiating a new chat clears the chat history. |
| Send feedback | Your feedback is valuable. Click a thumbs up for any helpful or accurate responses or a thumbs down if the response missed the mark. You can provide more details in the open text box. |

### Disable AI functionality

You can disable AI features or tools at any time. In the Administration space, select AI preferences and disable the tools you do not require. You can enable these tools and reapply them to your system at any time. For more details, see [Set AI preferences](/admin-space/latest/en/content/environment/as-ai-prefs).
